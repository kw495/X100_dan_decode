# DJ-X100 データファイル デコーダ（.dan / .dat）

アルインコの受信機 **DJ-X100** の EditTool が保存するメモリーデータ（`.dan` / `.dat`）を復号し、
メモリーチャンネル・プログラムスキャン・バンク・リンクの内容を **CSV** に書き出す Python スクリプトです。

EditTool 本体の「エキスポート」では出力されない **通信設定**（白色化コード、ユーザーコード、秘話コード、
グループコード、CTCSS／DCS、カラーコードなど）も、EditTool の画面と同じ表記で 1 項目 1 列に展開します。


## 特長

- `.dan`（EditTool Ver.1.01）と `.dat`（NXDN(N) 対応前の旧版）の両方に対応。旧形式のモード番号のずれも自動補正
- 通信設定の全項目を、EditTool の通信設定画面と同じ値（`AUTO` / `OFF` / `ALL` / `32767` など）で出力
- そのチャンネルのモードで有効な設定だけをまとめた「通信設定(現モード)」列
- 2 つのファイルの差分（追加／削除／変更）を出す比較ツール `compare.py` 付き
- Python 3.8 以上の標準ライブラリだけで動作（追加インストール不要）

## 使い方

### 復号して CSV に書き出す

```sh
python3 dan_decode.py 入力ファイル.dan 出力フォルダ
python3 dan_decode.py 入力ファイル.dat 出力フォルダ
```

Windows では `python3` を `py` に読み替えてください。

| オプション | 説明 |
|---|---|
| `--format dan` / `--format dat` | ファイル形式を明示します（省略時は拡張子で判定） |
| `--no-hex` | 復号後の生データ `plain_hex.txt` を出力しません |
| `--version` | バージョンを表示します |

出力されるファイル（CSV は UTF-8 BOM 付きで、Excel でそのまま開けます）:

| ファイル | 内容 |
|---|---|
| `memory_channels.csv` | メモリーチャンネル（使用中のもののみ） |
| `program_scans.csv` | プログラムスキャン |
| `bank_links.csv` | バンクリンク |
| `scan_links.csv` | スキャンリンク |
| `banks.json` | バンク A〜Z の名前 |
| `plain_hex.txt` | 全 1062 行の復号結果（16 進）。解析・検証用 |

復号できない行があった場合は警告を表示し、終了コード 1 を返します。

### 2 つのファイルを比較する

```sh
python3 compare.py 旧ファイル.dat 新ファイル.dan 出力フォルダ
```

`dan_decode.py` と同じフォルダに置いて実行してください。

| ファイル | 内容 |
|---|---|
| `compare_memory.csv` | メモリーチャンネルごとの区分（追加／削除／変更／番号移動のみ／同一）と変更項目（`旧 → 新`） |
| `compare_program_scan.csv` | プログラムスキャンの比較 |
| `compare_banks_links.csv` | バンク名・バンクリンク・スキャンリンクの差分 |
| `compare_summary.json` | 件数の集計（モード別・バンク別・差分の内訳） |

チャンネル番号は挿入・削除でずれるため、対応づけは **周波数＋名前**、見つからなければ **周波数のみ** で行います。
そのため、周波数が同じで名前を変えたチャンネルは「変更」として出ます。

## CSV の列（memory_channels.csv）

| 列 | 内容 |
|---|---|
| 番号, 周波数, 名前, モード, ステップ, スキップ, オフセットステップ | EditTool の一覧と同じ |
| 緯度, 経度 | 経緯度を設定している場合のみ |
| バンク, バンク割り当て状況 | 所属バンク（例 `AB`）とバンク名 |
| 標準機GUI | 標準機では非表示になるモードの場合に注記 |
| 通信設定(現モード) | そのモードで有効な設定の要約（例 `白色化コード=261 / … / シフト=-2.000000`） |
| 周波数シフト, アッテネータ | 全モード共通 |
| FM:スケルチタイプ, FM:CTCSSトーン, FM:DCSコード, FM/AM:音声反転秘話, FM/AM:反転周波数 | FM/NFM・AM/NAM タブ |
| T98:白色化コード, T98:ユーザーコード, T98:秘話コード, T98:グループコード | T98 タブ |
| T102/NXDN:白色化コード, …ユーザー(RAN)コード, …秘話コード, …グループコード | T102/B54 タブ（NXDN(N) も同じ値を使用） |
| DMR:受信スロット, DMR:カラーコード, DMR:グループコード | DMR タブ |
| T61(TYP1〜X):白色化コード, T61(TYP1/2):基準緯度・経度, ICDU:白色化コード | T61・ICDU タブ |
| D-STAR:コードスケルチ, C4FM:DG-ID | D-STAR・C4FM タブ |
| CommData(hex) | 通信設定の元データ（56 バイト） |

`program_scans.csv` も同じ通信設定の列を持ちます。

## 対応形式

| 形式 | 保存したツール | 備考 |
|---|---|---|
| `.dan` | DJ-X100 EditTool Ver.1.01 | NXDN(N) モード対応 |
| `.dat` | NXDN(N) 対応前の旧版 EditTool | モード番号 7 以上を +1 して読み込み |

ファイル形式の詳細は [docs/FORMAT.md](docs/FORMAT.md) を参照してください。

## 注意事項

- **読み取り専用** です。`.dan` / `.dat` を書き換えたり、受信機へ書き込んだりする機能はありません。
- 本ツールの利用によって生じた損害について、作者は責任を負いません。

## テスト

メーカー提供のデータや個人データは使わず、テスト内で合成したデータで検証
